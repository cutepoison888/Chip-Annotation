# 芯标注 · IC采购助手

**一个给电子元器件采购用的免费浏览器插件。开源、免费、本地运行、没有后台、没有病毒。**

适用于 **IC交易网（ic.net.cn）**、**正能量电子网（bom.ai）**、**华强电子网（hqew.com）**，支持 Chrome、Edge 以及 360、QQ 浏览器等 Chromium 内核浏览器。

> 每天在这几个网站上找货、点 QQ、问价、记报价、比价格，重复又容易乱。芯标注把这些步骤放到搜索结果页上，点一下就能完成，报价自动整理成一张表。

## 它能做什么

| 功能 | 说明 |
| --- | --- |
| **QQ 识别与一键复制** | 搜索结果里的 QQ 图标标出是**企业 QQ**（可直接聊）还是**私人 QQ**（要先加好友）。点一下自动复制号码，企业 QQ 直接打开会话。 |
| **询价记录本** | 点过的 QQ 自动记一行：日期时间、公司名、QQ、型号、品牌、批次。对方报价后在这一行直接填数量、价格（未税/含税）、货品、货期，像 Excel 一样边填边保存。点 ✓ 标为有效报价，同型号的最低价自动标出来，可导出 CSV 用 Excel 打开。 |
| **实时询价列表** | 搜索结果上方显示当前型号的询价记录，不用切换页面就能填报价；网页右侧的 📒 能在下半屏打开完整记录本。 |
| **批量询价** | 在每家公司后面打勾，插件逐家复制询价话术并打开对方 QQ，**由你自己粘贴、按回车发送**。插件不会替你发消息，每批最多 20 家。问过的公司会变成**绿色**并取消勾选，「只选企业」会自动跳过它们，方便接着问下一批。 |
| **货源对比** | 自动查同一型号在 **立创商城、云汉芯城、圣禾堂、贸泽、得捷** 的库存和价格，显示在搜索结果上方，型号必须完全一致。不需要的网站可以关掉。 |
| **库存价格监控** | 两种用法：① 在立创、云汉、圣禾堂、贸泽、得捷的**某一条商品**旁点「🔔 监控」，只盯这一条（立创按编号识别），库存和每一档价格都会比较；② 在三个网站货源对比条上点「🔔 加入库存价格监控」，监控这个型号在货源对比里开着的网站的库存合计和最低价。按你设定的间隔（30 分钟到每天）检查，库存变多、变少、到货、卖完，或价格涨、降时，弹出电脑通知。单独的「📈 库存价格监控」页面列出所有监控、下次检查时间，以及加入时和现在的库存、价格梯度对比，有变化的格子高亮。 |
| **公司名片一键复制** | 鼠标停在公司名上，显示网站自己的公司名片，一键复制公司名、联系人、电话、QQ、地址。 |
| **页面精简** | 隐藏广告横幅等多余内容，搜索结果更清爽。 |
| **深色模式** | 晚上看网页不刺眼。 |
| **网站登录状态** | 一眼看到三个网站是否已登录（插件不接触你的账号密码）。 |

## 安全说明：开源、免费、没有病毒、没有后门

- **完全开源**：本仓库就是插件的全部代码，任何人都可以逐行查看。你安装的就是 `extension` 文件夹里的这些文件，没有任何隐藏或加密的代码。
- **完全免费**：没有收费功能，没有广告，没有会员。
- **本地运行**：询价记录、设置、关注列表**只保存在你自己的浏览器里**（`chrome.storage.local`）。插件**没有服务器**，不上传、不收集任何数据。
- **不碰账号密码**：插件不读取、不保存你在任何网站的账号和密码。
- **不替你发消息**：批量询价只是帮你复制话术、打开 QQ 窗口，发送永远由你自己按回车。
- **不绕过验证**：插件只读取网页上本来就显示给你看的内容，不调用未公开接口，不绕过任何人机验证。

## 工作原理

芯标注是一个标准的 Chrome 扩展（Manifest V3），由几部分组成：

1. **页面脚本（content script）**：在 IC交易网、正能量网、华强电子网的页面上运行。它读取搜索结果里每一行的公司名、型号、品牌、批次和 QQ 图标，然后在页面上加上按钮、标签和询价列表。它只改你自己浏览器里看到的样子，不会修改网站服务器上的任何东西。
2. **QQ 识别**：根据网站本身给 QQ 图标加的标记（例如企点链接），判断是企业 QQ 还是私人 QQ。点击时复制号码，企业 QQ 通过 QQ 自己的链接打开会话。
3. **后台脚本（service worker）**：负责保存询价记录、查询货源和定时检查库存。
4. **货源对比与库存提醒**：查询货源时，插件在**后台标签页**里打开立创、云汉、圣禾堂等网站的公开搜索页，读取页面上显示的库存和价格，读完马上关闭标签页。就和你自己打开网页看一遍一样，只是由插件代劳。结果在本机缓存 3 小时，同时打开几个网站也只查一次。
5. **库存价格监控**：用浏览器自带的定时器（`chrome.alarms`）按你设定的间隔检查，和上一次的结果比较，有变化就用浏览器的系统通知提醒你。**浏览器开着才会检查**；浏览器关掉后不会检查，下次打开时如果已超过间隔，会自动补查一次。
6. **数据存储**：所有数据存在浏览器的 `chrome.storage.local` 里，只有本机的这个插件能读到。卸载插件，数据就一起删除。

## 安装方法

1. 下载插件：
   - 在本页右侧的 **Releases** 下载最新的 `芯标注-IC采购助手-v版本号.zip`，解压；
   - 或者点本页绿色的 **Code → Download ZIP**，解压后使用里面的 `extension` 文件夹。
2. Chrome 地址栏输入 `chrome://extensions` 回车（Edge 输入 `edge://extensions`）。
3. 打开右上角的「**开发者模式**」（Edge 在左下角）。
4. 点「**加载已解压的扩展程序**」，选择解压出来、里面有 `manifest.json` 的那个文件夹。
5. 点浏览器右上角的拼图图标，把「芯标注 · IC采购助手」固定到工具栏，方便打开设置。

> 解压出来的文件夹不要删除或移动，删了插件就没了。浏览器启动时如果提示「请停用开发者模式扩展程序」，点「保留」即可。

### 更新

下载新版本，覆盖原来的文件夹，然后到 `chrome://extensions` 点插件上的刷新按钮，再刷新打开着的网页。询价记录不会丢。

## 使用方法

1. 登录 IC交易网 / 正能量电子网 / 华强电子网，搜索一个型号。
2. 搜索结果上方出现**货源对比**和**询价记录本**。
3. 点对方的 QQ 图标：自动复制号码并记到询价记录本；对方报价后，直接在记录本里填价格。
4. 想同时问多家：在公司后面打勾，点右侧的「**批量询价**」。
5. 想等某个型号到货或降价：在立创等网站的某条商品旁边点「🔔 监控」（只盯这一条），或点货源对比上的「🔔 加入库存价格监控」（看各网站合计）。点「📈 库存价格监控」查看对比。
6. 点浏览器工具栏上的插件图标，可以设置：点私人 QQ 时的行为、页面精简、深色模式、货源网站、提醒间隔，还能点「模拟提醒」看看通知长什么样。

## 常见问题

**Q：会不会被封 QQ？**
插件不会自动发送消息，只是帮你复制、打开窗口，发送由你自己完成。批量询价每批最多 20 家，请不要短时间内大量群发。

**Q：网站改版后功能失灵了？**
插件是根据网页结构读取内容的，网站改版后部分功能可能读不到。询价记录本里的数据存在本机，不会受影响。欢迎在 Issues 里反馈。

**Q：收不到库存价格监控的通知？**
Mac 请到「系统设置 → 通知 → Google Chrome」允许通知；Windows 请在「设置 → 系统 → 通知」里允许浏览器通知。也可以在插件弹窗里点「模拟提醒」测试。

**Q：数据能换电脑吗？**
在询价记录本里点「导出 CSV」，可以用 Excel 打开保存。
